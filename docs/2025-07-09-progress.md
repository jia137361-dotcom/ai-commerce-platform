## 发现的问题

### 问题 1：账号数据未隔离 ⚠️
**现象：** `1355026750@qq.com` 同时是 Platform Ops 用户和 Buyer 客户

**影响：**
- 用户混淆：同一个邮箱在不同系统中扮演不同角色
- 数据风险：虽然 MedusaJS 用不同 token 区分 (user token vs customer token)，但容易出错

**数据库现状：**
```
user 表: user_01KWRYZAK351VRRNS48ZGF2Z75 (1355026750@qq.com)
platform_operator: admin role
customer: cus_01KWRZ0885J35Z8W63G75GXGN3 (1355026750@qq.com)
```

**解决方案：**
1. 修改 Buyer 邮箱为独立邮箱（如 buyer@test.com）
2. 或修改 Platform Ops 邮箱为独立邮箱

---

### 问题 2：Storefront 登录后空白页 ⚠️
**现象：** 登录后跳转到 `http://127.0.0.1:5174/account/sign-in` 显示空白

**排查过程：**
1. SignInPage 代码正常，登录成功后调用 `window.location.assign(safeReturnTo())`
2. `safeReturnTo()` 默认返回 `/account`
3. App.tsx 中 `/account` 路由存在，应该渲染 AccountHomePage

**可能原因：**
1. Publishable API Key 验证失败 - 后端返回 "A valid publishable key is required"
2. `/store/customers/me` 请求失败，导致无法获取客户信息
3. BuyerAuthProvider 初始化时 `getCurrentCustomer()` 失败

**排查方向：**
- 检查浏览器控制台是否有错误
- 检查网络请求是否成功
- 验证 publishable key 是否正确传递
