🤖 AI Worker 生成流程

Phase 2A: 核心
1
接收请求 Done
POST /ai/generate-product
输入: prompt, platform_product_id, supplier_product_id, variant_id, print_position
2
解析供应商上下文 Done
从MedusaJS获取: SupplierPrintSpec (打印规格)、SupplierProductVariant (颜色/尺寸)
确定打印区域、文件尺寸、DPI、安全边距
3
生成设计图 Done
调用图像生成API (Fal.ai / OpenAI DALL-E / DashScope)
或使用Mock模式跳过外部API
输出: design_image_url
4
图像处理 Done
✅ 图像标准化 (normalize)
✅ 导出打印文件 (print_file) - 符合SupplierPrintSpec
✅ 生成Mockup (模板合成)
✅ 生成Gallery缩略图
5
AI文案生成 Done
调用DeepSeek/Qwen生成: 标题、描述、标签、SEO元数据
输出: title, description, tags, seo
6
价格建议 Done
基于: base_cost + USD/CNY汇率 + markup_min/max
输出: price_suggestion
7
返回结果 Done
完整响应: design + print_file + mockup + gallery + title + desc + tags + seo + price
8
买家端AI设计入口 Todo
缺失: 买家端的AI设计页面 (AiDesignPage已存在但需完善)
设计编辑器、Design Now按钮、买家AI生图流程
9
批量生成 Todo

1个credit = 1次提示词 = 2张图片，可勾选5个产品类别
