# Phase 1 Dev2 Self-Test Results

This file is reserved for sanitized local self-test notes.

Do not commit real local output containing:

- `PUBLISHABLE_API_KEY`
- `ADMIN_TOKEN`
- full JWT values
- local-only secrets
- generated private order/cart/product ids if not needed

Use placeholders such as:

- `<PUBLISHABLE_API_KEY>`
- `<ADMIN_TOKEN>`
- `<ORDER_ID>`
- `<CART_ID>`

For the canonical testing flow, see:

- `docs/testing.md`
- `docs/phase2a-test-runbook.md`
- `docs/phase1-dev2-self-test.md`
